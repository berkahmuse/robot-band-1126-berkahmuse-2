## The entry

> The Blue Screens of Death — hit single 'Ctrl+Alt+Delete My Heart (Unsaved)'

## How it works

`main.py` is a deterministic program with no network, no randomness and no
secrets. It writes the band name and its hit song line to `/output/entry.txt`:

```sh
python3 main.py
cat /output/entry.txt
```

The text is 75 characters, inside the competition gate of 1–200 characters.
